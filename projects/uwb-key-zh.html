项目概述

本项目将 UWB 测距、状态估计和几何定位接入嵌入式门禁实验。核心技术问题是将两路带噪距离转换为相对门锁的稳定位置，并用于区域判决。

STM32 固件分离串口测量解析、线性标定、各基站滤波、双圆几何求解与本地状态输出；Windows 调试上位机显示距离、基站设置与定位结果，辅助开发。

数字钥匙赛题任务

2026 TI 杯辽宁赛区 C 题要求搭建无线数字钥匙和门锁实验系统。四位拨码开关设置匹配身份，LED 模拟开锁与闭锁，显示器报告身份、径向距离、方位角和当前判决。

官方工作区域为门锁正前方 ±45°，通信距离至少 3 m；1 m 内开锁，1—2 m 迎宾，2 m 外感应。规定误差目标分别为径向距离 0.3 m、方位角 10°、区域边界 0.2 m。这些是定义本工程问题的赛题目标。

线性标定：修正测距比例与偏置

源码中的处理顺序是原始 UWB 距离 → 仿射线性标定 → 标量卡尔曼滤波 → 双圆定位。串口解析器读取以毫米为单位的十六进制距离字段，再对输入距离进行比例与偏置修正。

标定模型：dc = a draw + b，其中 a 修正比例误差，b 修正固定偏置。采用线性回归离线标定时，将已知参考距离与对应原始读数配对，求使参考距离残差平方和最小的 a、b；固件运行时仅需逐次计算这一线性映射。

所提供源码实际写入的仿射映射约为 a = 0.994344、b = −520.441 mm。原始标定距离对与拟合记录未随工程提供，因此这里将系数作为实现设置，而非经过核验的标定精度结果。线性标定处理系统性距离偏差，时间滤波处理相邻采样的波动，两者作用不同。

卡尔曼滤波：稳定各基站距离序列

每个基站分别保存一维距离估计和不确定度。恒距离预测先沿用上一时刻估计，并通过过程噪声 Q 允许状态变化；再利用标定后的观测 z 和测量噪声 R 修正预测。

预测：d̂− = d̂上一时刻，P− = P上一时刻 + Q。
测量更新：K = P− / (P− + R)，d̂ = d̂− + K(z − d̂−)，P = (1 − K)P−。

增益 K 决定新观测相对预测值的权重。增大 Q 相对 R 的比例会加快对运动的响应，减小这一比例会增强平滑但带来更大滞后。先分别滤波再进行几何求解，可以减少两路独立距离波动直接传递到每一次坐标更新。固件将前两路滤波距离送入定位求解器。

双基站二维定位：由两路距离求坐标

设两个基站为 A₁、A₂，基线长度为 L，滤波距离为 d₁、d₂。两个圆方程相减，可得到交点弦在基线方向的位置：

s = (d₁² − d₂² + L²) / (2L)，再求 h² = d₁² − s²。设 e 为基线单位向量，n 为其法向量，则候选位置为 p = A₁ + s e ± √h² n。正负号对应镜像的两个解，固件在当前左右基站布局下选择 Y 较大的门前解。

坐标原点位于门锁中心，+Y 朝向门外，+X 朝右；源码默认基站位于 x = ±260 mm。求解器检查非正或非有限距离、基线过短、双圆无交点，以及目标过近基线等情况。方位角采用 α = atan2(x, y)。赛题以直径 600 mm 门锁外边界为径向零点，因此代码计算 r = max(√(x² + y²) − 300 mm, 0)。

决策阶段检查定位状态和四位身份比较结果，再按 r < 1 m 开锁、1—2 m 迎宾及外侧区域选择状态，通过 OLED、LED 与蜂鸣器反馈。±45° 是官方赛题的空间要求；所检查固件计算并显示方位角，当前区域决策实际使用距离与身份。

实现状态与下一步

提供的固件快照可以核对标定 → 滤波 → 几何定位链路及本地分区输出逻辑。下一步需要整理标定记录和移动标签的重复测量，以量化径向、角度误差及多径、遮挡情况下的表现。

后续集成包括完整的无线钥匙 ID 接收链路和显式的正前方角度门控。在所检查快照中，配置的示例钥匙 ID 与拨码值比较，方位角用于显示，当前距离分区判决与上述待集成步骤分开呈现。
